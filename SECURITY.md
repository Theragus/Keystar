# Security policy

## Supported versions

Security fixes go into the next release. Only the latest release is supported, so keep your installation up to date
([docs/deployment.md](docs/deployment.md) explains updating).

## Reporting a vulnerability

Please **do not open a public issue** for security problems such as sign-in or permission bypasses, exposure of
tokens or corporation data, or injection flaws.

Report them privately instead:
[Security → Report a vulnerability](https://github.com/Theragus/Keystar/security/advisories/new).

Include the Keystar version, what an attacker can do, and the steps to reproduce it. You will get a reply in the
advisory. Once a fix is released, the advisory is published and you are credited unless you would rather not be.
